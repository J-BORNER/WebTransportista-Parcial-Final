# API Transportista 🚗

Web Service para gestión de conductores con Node.js, Express y PostgreSQL.

## Endpoints

- `POST /conductores` - Registrar conductor
- `GET /conductores/:licencia` - Consultar conductor
- `GET /conductores` - Listar todos los conductores
- `GET /health` - Health check

## Desarrollo

```bash
npm install
npm run dev
